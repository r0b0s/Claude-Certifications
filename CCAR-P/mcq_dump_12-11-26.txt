#### **Question 1: Tool Scoping (Yes/No)**
**Scenario:** Select whether each tool should be included in a procurement agent's toolset:
* **A read-only catalog lookup tool that returns vendor and SKU information:** **YES** *(Essential read-only data lookup)*

#### **Question 2: Fabricated Citation Incident Response**
**Scenario:** A research summarization assistant generated a fabricated citation. Which two Diligence-competency actions should be taken?
* **Correct Answers:**
  1. **Sample recent summaries to estimate the fabrication frequency across the population** *(Move from anecdote to statistical rate)*
  2. **Review whether citation grounding controls exist anywhere in the current generation pipeline** *(Verify structural safeguards)*

#### **Question 3: Claude Code Permission Rules Review**
**Scenario:** A peer's draft rules grant unrestricted Bash access to all projects across developers. Which response is most appropriate?
* **Correct Answer:** **Replace unrestricted Bash with narrowly-scoped tool patterns that allow only the specific commands the workflows require, and add explicit deny rules for sensitive operations.** *(Least privilege + explicit deny rules that apply immediately)*

#### **Question 4: Controlled Experiment (A/B Test) Design**
**Scenario:** Which two design steps must be completed BEFORE running a controlled prompt experiment with random assignment?
* **Correct Answers:**
  1. **Determine the minimum detectable effect size and the sample size needed for power**
  2. **Define the hypothesis and the primary success metric for the comparison**

#### **Question 5: Tool Router vs. Capability Decomposition**
**Scenario:** A triage agent grew from 6 to 34 tools, reducing accuracy. Which two findings justify capability decomposition over adding a router?
* **Correct Answers:**
  1. **The 34 tools serve four distinct claim workflow domains within the triage scope.** *(Domain seam)*
  2. **Tool descriptions overlap across multiple claim categories within the agent's tool set.** *(Root mechanism of selection errors)*

#### **Question 6: AI-Generated PR Review Policy**
**Scenario:** A team lead proposes bypassing code review for AI-generated PRs under 50 lines. Which two Diligence objections should you raise?
* **Correct Answers:**
  1. **Removing review removes the verification mechanism that AI-generated output requires across the workflow.**
  2. **Line count is a poor proxy for the actual risk a code change introduces into the system.**

#### **Question 11: Dominant Cost Driver Optimization**
**Scenario:** Token cost is dominated by a long, repeated system prompt and large retrieved context per request. Which optimization directly targets both?
* **Correct Answer:** **Move the long, repeated system prompt into a cacheable prefix and trim retrieved context to the spans relevant to each query.** *(Prompt Caching + Context Minimization)*

#### **Question 12: AI Ethics Review Checklist**
**Scenario:** Which two checks belong on an AI ethics review checklist?
* **Correct Answers:**

  2. **Verify that outputs do not rely on generalizations about people that the underlying data does not support.**

#### **Question 13: Hiring Tool Evaluation Set Coverage**
**Scenario:** An evaluation set for a hiring tool is drawn from one geographic region and one tenure band. What is the correct move?
* **Correct Answer:** **Expand the evaluation set to cover the geographic regions and tenure bands the tool will serve, and rescore the system on the expanded set before broader release.**

#### **Question 17: Customer Refund Delegation Boundary**
